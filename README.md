# Micrographics Data YouTube video files

Public file host for videos generated from published Micrographics Data blog posts.
Metricool fetches each MP4 from its raw GitHub URL and publishes it to the Micrographics Data YouTube channel.

Layout: `videos/<article-handle>/` holds the MP4, English captions (`.en.srt`) and `metadata.md` (title, description, tags).
`tools/` holds the slide-video generator.
